# Sindopoly: A Monopoly-inspired University-themed online game

## Overview
This Thesis focuses on the development of "Sindopoly", an online game inspired by the traditional board game Monopoly, with the theme of the International Hellenic University (IHU).

## Objective
This project seeks to use a carefully selected range of modern web technologies to create an interactive and immersive gaming experience that reflects and captures the academic and social environment and atmosphere of DIPAE, while faithfully adhering to the classic Monopoly rules.

## Technology Stack
During the initial phase of the project, various frontend, backend and database technologies will be explored, with the aim of finding the most suitable for the specific project. These technologies include:

### Front End
- React + Threejs
- Unity

### Back End
- Spring Boot
- .NET
- Nodejs
- Redis

### Database
- MariaDB
- PostgreSQL
